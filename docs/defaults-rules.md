# Canonical defaults rules

Единый источник правил формы для объектов в `**/defaults.js` и при генерации schema/ACF. Синхронизировать с `scripts/check-defaults.js` и Cursor rule.

## Правила

- **link** — обязательно поля `href` и `target`. Значение по умолчанию для `target`: `'_self'`. Опционально: `text`, `label`.
- **image** — обязательно поля `src` и `alt`. Не допускать объект только с `src`.
- **repeater / group** — каждый элемент должен содержать полный набор полей по типу (те же ключи, что в эталоне). Не допускать «обрезанных» объектов (например link без `target`, image без `alt`).

## Проверки (для скрипта)

Проверяются только поля с **именем** `link` и `image` (не любой объект с url/src):

- Поле **link** (объект): обязательно `href` и `target`. Если нет `target` → нарушение.
- Поле **image** (объект): обязательно `src` и `alt`. Если нет `alt` → нарушение.
- В массивах объектов (repeater) у каждого элемента — те же ключи, что у первого или у эталона.
