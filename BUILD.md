# Где итоговая сборка

После команды **`npm run build`** результат лежит в папке **`.next/`**.

Чтобы её было видно в проекте, сделана **ссылка** (symlink):

- **`next-build`** — это та же папка, что и `.next` (открой `next-build` в боковой панели).

Реальная папка называется `.next`; в Finder и в редакторе она может быть скрыта (имя с точкой, плюс в `.gitignore`). Папка **next-build** ведёт в то же место и всегда видна.

## Как посмотреть собранный сайт

В `next-build` нет .html файлов — Next.js отдаёт страницы через сервер. Запусти:

```bash
npm run start
```

Открой в браузере: **http://localhost:3000** — это и есть «итоговый» сайт.

## Что внутри `.next`

| Папка/файл | Назначение |
|------------|------------|
| `.next/server/` | Серверные чанки и HTML |
| `.next/static/` | JS, CSS, шрифты (хешированные имена) |
| `.next/BUILD_ID` | ID текущей сборки |

Итоговые файлы для деплоя — вся папка **`.next`** (или **next-build**) плюс запуск через Node: `npm run start`. На хостинге (Vercel, свой сервер с Node) то же самое: загружаешь проект и запускаешь `npm run start` (или хостинг делает это сам).

**Деплой на PHP-хостинг:** проект настроен на статический экспорт. После `npm run build` в корне появляется папка **`out/`** — в ней лежат готовые .html, JS, CSS, картинки. Заливай содержимое `out/` в корень сайта на хостинге. Подробно — в **DEPLOY.md**.

**Локальный просмотр экспорта:** не открывай `out/index.html` через файловый менеджер (file://) — шрифты и скрипты не загрузятся. Используй `npm run preview` и открой http://localhost:3000.

## Сборка (напоминание)

Нужен **Node.js 20+**:

```bash
nvm use 20
npm run build
```
